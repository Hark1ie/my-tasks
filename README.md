# My Tasks

Personal to-do app: Android, Windows desktop and web, with real-time sync and widgets.

- `core/` shared data model and rules (ordering, sync, sorting, filters, repeats, settings) with tests
- `firebase/` Firestore security rules
- `docs/PLAN.md` plan, decisions and milestone status
- `android/` Android app (from milestone 2)
- `desktop/` desktop and web app (from milestone 6)

## Run the core tests

```
cd core
npm ci
npm test
```
